# Memory: Sprint 1.5

## Key facts for future sessions
- The agent is **HTTP long-polling**, not WSS. The public README no longer claims otherwise.
- The 8-layer security model is **not** shipped. Current layers: command whitelist, path deny list, execution timeout (SIGKILL), token rotation per heartbeat, outbound-only HTTP.
- No signed-command verification. `sha2` and `ring` are not in `Cargo.toml`.
- No `ws/`, `tools/`, nested `security/` module tree. Actual layout is flat: `config.rs`, `discovery.rs`, `heartbeat.rs`, `executor.rs`, `security.rs`, `health.rs`, `main.rs`, `lib.rs`.
- Health endpoint on `:9100` is opt-out via `--no-health`.
- No release has been cut. `release.yml` exists but has never fired. Installer URL `get.sigops.dev/agent` is aspirational.
- When implementing features from the Roadmap (WSS, mTLS, signed commands, sandbox, auto-update), update both code and README in the same PR.
